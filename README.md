# gsd

Get shit done — a personal task CLI backed by SQLite.

## Install

### Homebrew `--HEAD`

```sh
brew tap jmcampanini/gsd https://github.com/jmcampanini/gsd
brew install --HEAD jmcampanini/gsd/gsd
brew upgrade --fetch-HEAD gsd
```

### Source/dev build fallback

```sh
make build
# binary at ./build/gsd
```

## Verify

```sh
make check
```
